# Python-Scientific-Calculator
A feature-rich scientific calculator made in Python, perfect for Secondary/High School students

## Features
- Trigonometric functions
- Equation Solvers
- Base Conversion
- Random Number Generator
- Statistics functions
- Formulae for O Levels
- Word Problem Solvers

## Requirements
### Windows version (.exe)
- A computer running Windows, preferably Windows 10 or later
### Raw Python file (.py)
- Python 3.6+ (3.13 reccomended)

## Installation
### Windows version
1. Download ScientificCalc.exe from releases
2. Open ScientificCalc.exe
### Raw Python file
1. Install Python at python.org
2. Download ScientificCalc.py
3. Open ScientificCalc.py
